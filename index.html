Panduan Setup (3 Langkah)
① Buat Google Sheets
Buka sheets.new → beri nama "Rekap Piket Deteni"
② Buka Apps Script
Di Sheets: menu Ekstensi → Apps Script → hapus kode lama → paste kode dari file apps-script.gs yang sudah diunduh
③ Deploy sebagai Web App
Klik Deploy → New deployment → pilih tipe Web App → Execute as: Me → Who has access: Anyone → klik Deploy → copy URL-nya
④ Paste URL di atas
Tempel URL tadi di kolom "URL Apps Script" → Simpan & Hubungkan ✅
